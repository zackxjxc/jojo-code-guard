## jojo-code-guard 自动加载（必须严格遵守）

- 每次会话启动时自动加载并应用 `jojo-code-guard` Skill。
- 这是每个会话处理用户消息前的第一项动作，不得因消息看似闲聊、与代码无关或隐式调用相关性不足而跳过。
- 必须先读取已安装插件中的 `skills/jojo-code-guard/SKILL.md` 正文，再生成任何回复；读取失败或 Skill 不可用时暂停并报告。
- 所有任务都必须受该 Skill 的保护规则约束，特别是涉及文件编码、BOM、换行、Git 空白错误
  和异常 diff 的场景。
- 修改任何文件前，必须按 Skill 记录仓库状态、目标文件的编码、BOM、换行和已有未提交修改，
  确认本次变更边界；已有修改不等于污染。编辑后再次检查。
- 如 Skill 未成功加载，暂停并报告。检查发现异常时，先阻止交付、提交和推送；若异常位于明确授权的
  目标内，可依据仓库规则、编辑前状态或 Git 基线精确恢复，且不会改变用户内容语义或覆盖无关修改，
  则自动最小修复并复检。只有异常来源不明、需要猜测原始状态、可能覆盖用户修改或连续修复失败时，
  才暂停并请求用户处理。
