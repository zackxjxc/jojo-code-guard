# 原生发现与旧版迁移

Codex 和支持 Skills 的客户端使用名称、描述和当前任务进行原生发现。插件不再要求把自动加载节写入用户级
`AGENTS.md`/`CLAUDE.md`，也不通过 `SessionStart` 注入 Skill 正文或“每次回复前重新读取”的指令。

## 当前规则

- 纯聊天和不访问本地文件的任务不加载 jojo-code-guard。
- 文件编辑、编码/BOM/EOL 诊断或异常 diff 任务命中主 Skill 后，当前上下文已完整加载且版本未变化时直接复用。
- 新线程、上下文压缩后必要规则缺失、Skill 版本变化或独立代理未继承规则时，由客户端按需重新读取。
- 项目 `AGENTS.md` 由 Codex 原生按全局、项目根和当前目录层级发现；插件不再次注入或拼接。
- 多个 Hook 配置层会分别执行，用户级旧版 jojo Hook 应移除，避免与插件 Hook 重复。

## 旧版配置

0.2.x 的 doctor 可能在 `~/.codex/AGENTS.md` 或 `~/.claude/CLAUDE.md` 写入
`## jojo-code-guard 自动加载` 一节，也可能留下用户级 `SessionStart` Hook。升级后 doctor 只报告这些旧配置；
删除前应审阅精确节和 Hook 来源，不覆盖同一文件中的其他用户规则。
